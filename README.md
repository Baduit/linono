# linono
A tool to know when the releases of the light novels I like

It extract the information from the wikipedia page of the ligh novel then expose it. The main logic is in rust, there is a simple GUI made with [egui](github.com/emilk/egui) and also python binding to make a python cli using [rich](https://github.com/Textualize/rich) library (there is also a debug rust cli).

I also made a github page by using the python cli to output an html file instead of printing it on the console. The whole thing is a mess of libs and tech I wanted to try so this is normal that it does not make any sense.
